# 淘宝用户行为分析报告

> 基于天池公开数据集 UserBehavior（抽样100万条）的用户行为深度分析，覆盖流量转化、用户留存、复购、RFM分层与商品品类五大维度，并配套 SQL 脚本、Python 分析代码和 Power BI 可视化看板。

---

## 一、项目背景与目标

### 1.1 业务背景

淘宝是中国最大的电商平台，用户从"浏览 → 加购/收藏 → 购买"的每一次行为都蕴含着巨大的商业价值。理解用户的行为规律，对于提升转化效率、优化留存策略、精准用户运营具有直接的业务指导意义。

### 1.2 数据来源

| 项目 | 说明 |
|------|------|
| 数据来源 | 阿里云天池公开数据集（数据ID: 649） |
| 原始规模 | 约1亿条行为记录（约3.67GB） |
| 分析样本 | 随机抽样 1,000,000 条 |
| 时间范围 | 2017-11-25 ~ 2017-12-03（共9天） |

### 1.3 数据字段

| 字段 | 含义 | 说明 |
|------|------|------|
| user_id | 用户ID | 脱敏处理 |
| item_id | 商品ID | 脱敏处理 |
| category_id | 商品类目ID | 脱敏处理 |
| behavior | 行为类型 | pv浏览 / cart加购 / fav收藏 / buy购买 |
| timestamp | 时间戳 | 距离2017-11-25的秒数 |

### 1.4 分析目标

1. **流量与转化**：PV/UV、日活趋势、小时级活跃规律、转化漏斗分析
2. **用户留存与复购**：次日/7日留存曲线（cohort分析）、复购率与复购周期
3. **RFM用户分层**：基于最近购买时间和购买频次进行用户价值分层
4. **商品与品类**：Top商品/品类排行，识别高价值品类

## 二、核心结论（100万样本实测数据）

### 2.1 流量概览

| 指标 | 数值 |
|------|------|
| PV（浏览量） | 896,106 |
| UV（独立用户） | 9,739 |
| 人均浏览 PV/UV | 约92次 |
| 收藏数 | 28,088 |
| 加购数 | 55,447 |
| 购买数 | 20,359 |

### 2.2 转化漏斗

```
浏览 896,106 (100%)
  ↓ 9.32%
收藏+加购 83,535
  ↓ 24.37%
购买 20,359 (2.27%)
```

| 转化环节 | 转化率 |
|----------|--------|
| 浏览 → 收藏/加购 | 9.32% |
| 收藏/加购 → 购买 | 24.37% |
| 浏览 → 购买（整体） | 2.27% |

**核心发现**：漏斗最大的"漏水点"在"浏览 → 收藏/加购"环节（流失约90.7%），而"收藏/加购 → 购买"的转化率相对健康（24.37%）。这说明用户一旦表达出收藏/加购意愿，购买意愿已经较强，关键在于**如何提升浏览用户向"有意向用户"的转化**。

### 2.3 用户留存

| 留存指标 | 数值 |
|----------|------|
| 次日留存率 | 74.25%（7,231人） |
| 7日留存率 | 82.55%（8,040人） |

> 说明：由于数据集时间跨度仅9天，留存计算基于"首日新增用户在后续日期是否再次活跃"，数值偏高。建议在完整数据集（覆盖更长周期）上做更严谨的 cohort 留存分析。

### 2.4 复购分析

| 指标 | 数值 |
|------|------|
| 购买用户数 | 6,689 |
| 复购用户数（≥2次购买） | 4,429 |
| **复购率** | **66.21%** |

**核心发现**：复购率高达66.21%，说明淘宝用户一旦完成首次购买，有约三分之二的概率会再次购买，复购用户是平台的核心价值人群。

### 2.5 商品品类 Top10

| 排名 | 品类ID | 行为次数 |
|------|--------|----------|
| 1 | 4756105 | 51,877 |
| 2 | 4145813 | 33,841 |
| 3 | 2355072 | 32,571 |
| 4 | 3607361 | 31,226 |
| 5 | 982926 | 30,797 |

### 2.6 时间活跃规律

| 指标 | 数值 |
|------|------|
| 小时峰值 | **13点**（PV=75,094） |
| 高峰时段 | 12-14点（午间） |
| 工作日PV | 474,866 |
| 周末PV | 421,240 |

**核心发现**：活跃高峰集中在**午间12-14点**（13点达到峰值75,094次），而非晚间。工作日PV高于周末，说明淘宝用户在工作日午休时段有较强的"逛淘宝"习惯。

## 三、详细分析与业务建议

### 3.1 流量与活跃分析

**发现**：
- 小时级活跃呈现明显的"午间峰值"特征，13点达到全天峰值（75,094 PV），12点、14点紧随其后。
- 工作日PV（47.5万）高于周末（42.1万），工作日午休时段是流量黄金窗口。

**业务建议**：
- **午间12-14点加大投放**：在午休时段集中投放首页曝光、限时秒杀、优惠券推送，最大化流量转化。
- **针对工作日制定差异化运营**：工作日主打"午休碎片化购物"，周末主打"休闲娱乐型购物"，推送内容区分。

### 3.2 转化漏斗分析

**发现**：
- "浏览 → 收藏/加购"转化率仅9.32%，是漏斗最大瓶颈（流失90.7%）。
- "收藏/加购 → 购买"转化率24.37%，相对健康，说明"有意向用户"的购买意愿较强。

**业务建议**：
- **优化商品详情页**：提升商品图片质量、完善详情描述、突出卖点，降低浏览用户"看不进去就划走"的概率。
- **降低加购/收藏门槛**：简化加购按钮位置、优化购物车入口，让用户更容易"留下意向"。
- **对"已加购/已收藏未购买"用户实施48小时催付**：这类用户购买意愿强（24.37%），是性价比最高的召回人群，可推送限时优惠券+倒计时提醒。

### 3.3 留存与复购分析

**发现**：
- 次日留存率74.25%，7日留存率82.55%，整体留存表现良好。
- 复购率高达66.21%，复购用户（4,429人）占购买用户（6,689人）的三分之二。

**业务建议**：
- **建立复购用户专属权益体系**：对复购用户提供会员积分、定向折扣、专属客服等权益，强化复购习惯。
- **首单转化是关键**：首次购买的体验直接影响后续复购。对首次购买用户提供"首单礼包"（优惠券、积分），提升首单满意度和复购概率。
- **对低留存cohort实施差异化召回**：短期（7天内）用优惠券+推送，长期（30天+）用邮件+会员权益。

### 3.4 RFM 分层与用户运营

**发现**：
- 基于 Recency（最近购买时间）和 Frequency（购买频次）可将购买用户划分为不同价值层级。
- 复购用户（F≥2）是核心价值人群，占比66%。

**业务建议**：

| 用户分层 | 特征 | 运营策略 |
|----------|------|----------|
| 重要价值用户 | 最近购买 + 高频次 | 专属权益、VIP服务、深度会员运营 |
| 重要保持用户 | 近期购买 + 中频次 | 持续激励、提升购买频次 |
| 重要发展用户 | 高频次但近期未买 | 召回唤醒、新品推荐 |
| 重要挽留用户 | 近期购买但低频次 | 首单后续转化、复购引导 |
| 一般用户 | 低频低频 | 精准推荐、提升首单转化 |

### 3.5 商品与品类分析

**发现**：
- Top5品类贡献了显著的行为量，头部品类集中度高。
- 品类4756105以51,877次行为位居第一，是平台流量和转化的核心品类。

**业务建议**：
- **头部品类重点运营**：对Top品类加大库存保障、促销力度和曝光资源，巩固优势。
- **长尾品类做关联推荐**：利用商品购买关联分析（Market Basket Analysis / Apriori），在用户购买头部品类时推荐关联长尾品类。
- **品类差异化定价**：高频复购品类适合"走量"策略，高客单价品类适合"精准营销"。

## 五、差异化亮点

本项目区别于 GitHub 上大量"流水账"式淘宝行为分析，具备以下差异化：

1. **SQL + Python 双引擎**：复杂分析（留存cohort、漏斗、RFM）用 SQL 窗口函数和子查询实现，证明真实的大数据 SQL 能力；Python 负责可视化和补充统计。

2. **每个结论跟业务建议**：不只报告"转化率9.32%"，而是给出"午间12-14点加大投放""对已加购未购买用户48小时催付"等可执行建议。

3. **RFM分层 + 运营策略映射**：将 RFM 分层结果直接映射到具体的用户运营动作，体现从数据到业务决策的完整闭环。

4. **README 即报告**：本文件本身即是一份完整的数据分析报告，不看代码也能理解分析思路和结论。
